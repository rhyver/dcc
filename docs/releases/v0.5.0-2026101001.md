# DCC v0.5.0-2026101001

DCC remains in alpha. This release brings campaign planning improvements and moves downloads
and automatic updates to GitHub.

- Play supported scenarios from either coalition. Red-side campaigns use matching map colors,
  faction assignments, briefings, and objectives.
- Move, insert, and remove navigation waypoints for player flights before takeoff.
- Show or hide campaign map layers, including flights, ground/naval forces, airfields,
  objectives, structures, radar/SAM sites, frontline, pilots, and SAM ranges.
- Set enemy AI skill with a stepped slider, or let DCS randomize it per unit.
- Configure DCS assists per campaign: unlimited fuel, unlimited ammunition, invulnerability,
  Mini HUD for Flaming Cliffs aircraft, and stepped unit labels. All default to off.
- Choose East/West Germany 1985, USAFE 1955/1967, and GSFG 1955/1967 factions with their
  aircraft rosters and ground templates. Germany terrain and Fulda Gap are not included.

## Downloads and updating

Download Windows installers and Linux x64 AppImage/Debian packages from
<https://github.com/rhyver/dcc/releases>.

New Windows installations check GitHub for automatic updates. Older installations still
check Codeberg until they receive this transition build; installing the new Windows package
manually also moves them to GitHub. Linux updates remain manual.

Existing campaigns remain compatible. Back up campaign saves before upgrading an alpha build.

## Validation

Automated tests cover legacy campaign settings, assist persistence, faction rosters, mission
country identities, and generated mission files. Live DCS generation/play/import verification
of the newly ported options remains outstanding.
